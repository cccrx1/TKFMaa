## 叠甲

项目目前主要为我自己日常使用。更新和测试不一定充分，发布版本也可能有功能不完善、识别错误或非预期操作。建议先从少量任务开始，涉及购买和资源消耗时请留意设置与运行结果。

## 主要功能

- [x] 启动游戏
- [x] 商城购买
- [x] 领取体力
- [x] 炼金订单
- [x] 每日派遣
- [x] 消耗体力（随缘更新~）

- [x] 全境征才（醋包饺~）
- [x] 奖励领取

## 开始使用

以下步骤适用于 Windows 模拟器：

1. **下载完整包**：前往 [发布页面](https://github.com/cccrx1/TKFMaa/releases)，选择与你的系统和架构对应的完整包。
2. **解压并安装依赖**：解压到新文件夹，运行包内的 `DependencySetup_依赖库安装_win.bat`，按提示安装依赖。
3. **连接游戏**：启动模拟器和游戏，再打开 `MFAAvalonia.exe`，选择对应设备，确认能正常看到游戏画面。
4. **选择任务**：第一次建议先运行“启动游戏”，再检查其他任务选项并按需运行。多数日常任务需要从游戏主界面开始。

## 注意事项

- 每日派遣需要先在游戏内进行过一次派遣，助手不会自动编队。
- 画面异常或运行时闪退：可在客户端设置中尝试其他截图方式。
