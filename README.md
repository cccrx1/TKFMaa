# TKFMaa

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的「天下布魔」日常自动化助手

</div>

## 安装与使用

1. 下载最新 Release 压缩包并解压
2. 运行 `DependencySetup_依赖库安装_win.bat`
3. 运行 `MFAAvalonia.exe`

## 注意事项

闪退的话设置里更换一下截图方式~
有问题可以提issue，最近没啥时间，有时间会尝试优化的❤️

## 主要功能

- [x] 启动游戏
- [x] 商城购买
- [x] 领取体力
- [x] 炼金订单
- [x] 每日派遣
- [x] 消耗体力（随缘更新~）
- [x] 调教
- [x] 全境征才（为这顿醋包的饺子:)）
- [x] 奖励领取
- [ ] 协会奖励领取没做呢:(
