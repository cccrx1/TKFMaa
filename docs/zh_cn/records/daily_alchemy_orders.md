# 炼金订单（DailyAlchemyOrders）验证记录

## 覆盖状态

- 按钮完全缺失的页面尚未验证，当前进入炼金后的候选仅包含加载和收取按钮，不能宣称支持缺失按钮时跳过。
- 修复只调整抽屉打开与返回等待；实际交付已在修复前覆盖，修复后尚无新订单可再次验证。
  按钮缺失、网络慢加载、订单数量上限及仓库异常分支仍待验证。
