# 自动战斗（AutoBattle）验证记录

本文件记录自动战斗（AutoBattle）的实机验证、调试与覆盖状态，入口节点 `AutoBattleStart`；流程、识别依据和限制见 [自动战斗（AutoBattle）](../tasks/auto_battle.md)。

## 覆盖状态

- 自动通关功能当前已从 Interface 任务列表撤下，Pipeline 保留待后续优化；本轮自动通关端到端验证已停止。

- 体力阈值（基础预设为 50）、体力解析失败、回复弹窗取消、翻页/进入上限及未知页面退出均待实机验证。
- 复刻活动自动通关尚未实现；左右手势、边界、单列扫描次数和返回落点需先实机采集，不能用 `max_hit` 推测边界。
- 本次文档拆分只核对当前实现，没有新增实机验证；消耗体力的导航验证不能视为自动战斗已验证。

## 验证记录

- 2026-09-13 实机验证：从主界面直接启动，未进入关卡列表时任务立即安全停止；未启动战斗、未消耗体力。
- 已修复 `AutoBattleStart` 缺少主界面安全退出分支的问题。
- 2026-10-12 在第二页运行旧流程时，`NEW` 模板识别分数约 0.42–0.48（阈值 0.75），任务未进入关卡并返回主界面，体力未变化。之后人工定位 NEW 时误触“开始”，发生一场万圣-04 战斗并消耗 30 体力；没有运行自动战斗流程完成该关卡。按用户要求停止自动通关测试并从 Interface 撤下任务，相关功能改进待后续进行。
