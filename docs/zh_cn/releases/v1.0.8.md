# v1.0.8

本次为完整更新，包含前端更新机制修复、运行环境和活动配置。请下载对应系统和架构的完整包；本版本继续使用主仓库作为更新源，尚未切换到独立资源通道。

## 更新内容

- 整合固定版本前端补丁，修复更新失败后的界面状态、自动重启锁和更新日志写入时机。
- Windows 客户端使用独立的进程临时目录及 Agent TCP，规避已复现的 Agent 连接异常。
- 加入更新包缺失 Agent 入口、识别模板等内容的预检；在线更新缺少有效 SHA256 时拒绝下载。
- 将资源包和完整包构建分离：兼容现有环境的活动、识别流程、图片及 Agent 逻辑可单独打资源包；前端和运行依赖变更仍需完整包。
- 适配常规活动“新大陆历险记”的访查、记录、撰写、锻造、获取、拍摄六个 -01 关卡；归档旧活动，保留常驻战争演习。
- 活动列表换期后，旧关卡选择失效并默认选择“新大陆历险记 - 访查-01”，其余任务设置保留。
- 改进派遣、征才等任务的完成确认，并修复炼金交付与奖励领取在响应尚未完成时提前继续的问题。

## 更新说明

- 内置 Python 3.12、MaaFramework 5.14.3；前端为 MFAAvalonia 2.16.2 固定源码加本项目补丁。
- 首次接入新更新机制需要本次完整更新。建议将完整包解压到新目录，保留旧目录和配置备份，确认连接及任务选项后再使用。
- 与原版 2.16.2 相同，前端需要系统提供 .NET 10 运行环境；本包没有新增 Agent 安装依赖。
- 正式资源通道尚未启用。本次不会把已有客户端迁移至测试仓库；后续运行环境升级也不会仅通过资源包替换依赖。

## 验证范围

- Windows x64 已验证 Agent 连接、实时画面、资源更新与完整包更新、异常回滚和重启；其他平台以构建及包内校验为准。
- 新活动六个关卡已验证识别、进入详情与返回；本次没有执行消耗体力的扫荡或战斗验证。
- 本机默认 DirectML 资源校验仍存在异常，CPU 模式资源校验已通过。
