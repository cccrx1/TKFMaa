# 商城购买（DailyShop）

从城堡进入商城的每日兑换，在每家店内先处理清单中的贵重品，再处理普通品。仅访问交易所和协会商店，不进入充值、礼包或其他兑换页。

## 使用前提

- 游戏位于城堡主界面，且两个商店可访问。
- 交易所和协会商店分别使用自己的购买清单及商店货币。执行任务会实际消耗对应货币。

## 购买清单

在「指定购买物品」和「指定协会商店购买物品」中用 `|` 分隔目标。交易所的紧急录用证、招募命令，以及协会商店的召唤契约、魔晶石、阿克色记录，在**已经列入对应清单**时自动优先处理，未配置的商品不会因此被买入。

其他商品可用 `!商品全名` 设为贵重品。贵重品清单填全名，运行时允许 OCR 读到部分标题。普通品建议填全名，也可填两个字以上的片段。例如 `记忆精粹` 会匹配不同角色的记忆精粹。

## 扫描与确认

1. 每家店在确认页签和滚动端点后，顶部、底部各读取一份六格货架。同一格的标题和价格画面未变化时复用识别结果；返回列表时重新确认所在端点并核对下一候选的售罄状态。顶部普通品可等底部贵重品处理完，再回顶处理已有候选，不重扫两店。
2. 贵重品接受全名、一字近似，或至少三个字且覆盖目标全名一半的连续片段。一字近似允许长度至少为四个字的标题错一字，也允许多读或漏读一字且较短的标题至少有三个字。详情读到目标全名时通过。详情只读到近似标题时，它必须唯一指向原候选，且卡片已读到目标全名或与详情读到同一个近似标题。两处读法互相冲突时跳过。每店合计最多探查两个标题漏读的栏位，详情须读出本店待确认贵重品的唯一全名。
3. 普通品也可按近似标题打开详情。清单填全名时，详情完整标题必须与清单一致。清单填片段时，详情完整标题必须与卡片的完整标题一致，并包含该片段。
4. 售罄横幅须在各栏位的预期位置命中模板，只跳过命中的栏位。同名商品仍可从其他栏位识别或通过漏读探查确认。再次扫描货架时重新核对先前判为售罄的栏位，横幅不确定的栏位仍可进入详情复核。
5. 每次扣款前都需要识别详情页、与候选对应的标题以及「购买」按钮。已发现同名的栏位和标题漏读的栏位还要求卡片和详情的价格、数量一致，且详情货币属于本店；读不清就跳过。一次任务中同一栏位最多打开一次，发出购买点击后即使结果未知也不重试。通过奖励文案确认购买结果。
6. 结束后点击「城堡」，由公共节点确认已回到主界面。

## 异常与范围

- 售罄、详情不匹配、购买按钮不明或已识别到持有不足时不购买；能确认返回列表时继续检查其他栏位，不因单件货币不足直接跳过另一商店。
- 当前支持实机观察到的三列四行布局（顶部和底部各两行）。端点、布局或弹窗无法确认时停止当前路径，不在未知页面尝试购买。商城内容、语言或 UI 布局变化后需重新核对识别。
- 扫描完成不等于清单买齐。有些商品当日未上架、已售罄或无法可靠识别；候选详情以及未确认的贵重目标可在识别日志中排查。
