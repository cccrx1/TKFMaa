# 商城购买（DailyShop）

从城堡进入商城的每日兑换，在每家店内先处理清单中的贵重品，再处理普通品。仅访问交易所和协会商店，不进入充值、礼包或其他兑换页。

## 使用前提

- 游戏位于城堡主界面，且两个商店可访问。
- 交易所和协会商店分别使用自己的购买清单及商店货币。执行任务会实际消耗对应货币。

## 购买清单

在「指定购买物品」和「指定协会商店购买物品」中用 `|` 分隔目标。交易所的紧急录用证、招募命令，以及协会商店的召唤契约、魔晶石、阿克色记录，在**已经列入对应清单**时自动优先处理，未配置的商品不会因此被买入。

其他商品可用 `!商品全名` 设为贵重品。普通品建议填全名；也可填两个字以上的片段，此时多个全名都可能符合。例如 `记忆精粹` 会匹配不同角色的记忆精粹。贵重品必须填全名，不支持片段购买。

## 扫描与确认

1. 每家店在确认页签和滚动端点后，顶部、底部各读取一份六格货架。同一格的标题和价格画面未变化时复用识别结果；返回列表时重新确认所在端点并核对下一候选的售罄状态。顶部普通品可等底部贵重品处理完，再回顶处理已有候选，不重扫两店。
2. 贵重品用卡片全名或唯一的近似标题定位，详情只接受对应清单的全名。只有一个贵重目标尚未确认时，每店最多打开两个标题漏读的栏位，不逐格打开其他商品。普通品优先用全名或用户填写的片段定位；片段模式仍要求卡片与详情的完整标题一致。近似匹配只能打开详情，不能直接购买。
3. 每格用独立的横幅模板判断售罄；卡面英文不作售罄依据。横幅不确定时不直接排除该格，只有匹配清单的候选才进入详情检查。
4. 每次扣款前都需要识别详情页、与候选对应的标题以及「购买」按钮；识别到同名栏位时还会核对价格、兑换货币和数量。一次任务中同一栏位最多打开一次，发出购买点击后即使结果未知也不重试。奖励文案未识别时，不凭一个通用「确定」按钮认定成功。
5. 结束后点击「城堡」，由公共节点确认已回到主界面。

## 异常与范围

- 售罄、详情不匹配、购买按钮不明或已识别到持有不足时不购买；能确认返回列表时继续检查其他栏位，不因单件货币不足直接跳过另一商店。
- 当前支持实机观察到的三列四行布局（顶部和底部各两行）。端点、布局或弹窗无法确认时停止当前路径，不在未知页面尝试购买。商城内容、语言或 UI 布局变化后需重新核对识别。
- 扫描完成不等于清单买齐。有些商品当日未上架、已售罄或无法可靠识别；候选详情以及未确认的贵重目标可在识别日志中排查。
